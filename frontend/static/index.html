O projeto

Mais organização. Menos confusão.

O Seringa nasceu para transformar um processo muitas vezes fragmentado numa experiência digital clara: conhecer o ambiente, registar o que aconteceu e encontrar o histórico quando for necessário.

🏠 Um Hall de Entrada

Depois do acesso, o utilizador encontra uma casa digital. Os módulos aparecem como salas, para que seja fácil escolher o ambiente certo sem misturar contextos.

🔒 Privacidade como princípio

A arquitetura privilegia armazenamento local e uma abordagem offline-first. O objetivo é reduzir dependências e manter os registos sob controlo do utilizador.

📱 Feito para o telemóvel

Interface pensada primeiro para ecrãs pequenos, com ações diretas, cartões simples e navegação curta.

🧭 Informação organizada

Os módulos ajudam a acompanhar sessões, zonas, sintomas, ciclos, stock, evolução e outros registos adequados a cada ambiente.

Segurança e limites

O Seringa apoia. Não substitui o profissional.

O app não prescreve, diagnostica, altera doses nem autoriza a administração. Os registos de dose acompanham planos já definidos. Os mapas servem para documentação e organização, não para indicar uma técnica clínica.

Quando existe uma dúvida clínica ou um sinal de alerta, a orientação é procurar um profissional de saúde. O projeto foi desenhado para apoiar a pessoa, não para tomar decisões médicas por ela.
